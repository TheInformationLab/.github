# Data engineering track: extra guidance

This page adds to the [The Data School About page](https://thedataschool.co.uk/about/), which is where to start. The About page explains how the programme works, the two tracks, where they run, the contract and how to apply.

## What you build

For the engineering track you build a small data pipeline and publish it in a public GitHub repository. It has to be new work, built for this application. If you have a portfolio, we will look at it for context, but we judge the repository you submit.

1. Pick a free API on a subject you care about. Choose one with enough mess that you have to make decisions. A single endpoint returning ten tidy rows will not give you much to talk about.
2. Commit the raw response exactly as it came back, before you change anything.
3. Shape it into a clean, consistent table, or a small data model of several tables that relate to each other.
4. Use it: an app, a dashboard, a report or an alert. We weigh this part lightest.
5. Write a README for the project.

The About page lists the languages we accept.

## Before you send it

An incomplete submission is unlikely to be selected for the next stage, so check each of these first.

- The repository is public.
- It is new work, built for this application.
- The raw data is committed exactly as the API returned it, and nothing edited it afterwards.
- There are no API keys, tokens or passwords in the code or its history.
- Everything after the raw data runs from a clean clone.
- You committed as you went, so the history shows how you worked.
- The README covers who the project is for, the data, how it works, how to run it, what you would do next and where AI helped. It also includes a short note about you: your aims for the project and why you are applying.

## What we look for

We care most about how you get the data into shape. A strong submission solves a specific problem for a specific person, and you can say who would use it and what you left out on purpose.

You can use AI. Tell us where it helped, what you kept and what you changed, and be ready to talk an engineer through your project.

## What happens next

If we select your submission, we will invite you to talk it through with us. The [apply page](https://www.thedataschool.co.uk/apply/) has the current stages.
